# FutureIntern · Python games and utilities

Five Python scripts, from basic arithmetic to a graphical Snake game.

- [Calculator and beginner exercises](./futureintern_pd_01.py)
- [Rock, paper, scissors](./futureintern_pd_02.py)
- [Tic-tac-toe](./futureintern_pd_03.py)
- [Snake with Pygame](./futureintern_pd_04.py)
- [Password generator exercise](./futureintern_pd_05.py)

Run a script with Python 3, for example `python futureintern_pd_02.py`. The graphical Snake game also requires Pygame (`python -m pip install pygame`).
